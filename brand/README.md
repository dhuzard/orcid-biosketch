# Science Record Player — brand assets

The logo is a record on a turntable whose label is a play button: your science **record**, played in many formats. It has no link to ORCID's visual identity (no green, no "iD" circle).

| File | Use |
|---|---|
| `mark.svg` | App icon (aubergine tile). Copied to `web/playground/icon.svg`; source of `icon-192.png` / `icon-512.png` (maskable, padded) |
| `mark-on-dark.svg` | Pink tile, for dark backgrounds: site header, demo title cards |
| `favicon.svg` | Simplified mark for browser tabs (thicker strokes, no grooves). Copied to `web/playground/favicon.svg`; `favicon.ico` holds 16/32/48 px renders |
| `wordmark.svg` / `wordmark.png` | Mark + "Science Record Player" + "PUBLISH OR PLAY", for README, slides and posts |
| `mark-1024.png` | High-resolution mark for social avatars and app stores |

Colours: aubergine `#3a2737`, vinyl `#21181f`, muted pink `#e2b4c0`, rose text `#a05a72`, paper `#faf6f7`.
