# Research network — people, outputs and contacts

Open the [research network](https://orcid-playground-889.web.app/network/). You can use labelled sample data or import public ORCID records.

The hosted version runs the research-network engine in the browser. A separate, optional localhost Python/SQLite pilot also exists. They are **not** a public shared database.

## Feed

Follow people and see outputs discovered on later refreshes. You can scope the feed by researcher, group or private contact tag, select output types and refine topics. A newly observed item can have an older publication date; **discovery time is not publication time**. Refresh is manual in the local pilot, not continuous monitoring.

## People

Import an ORCID iD, inspect public works, follow a researcher, save selected outputs, and remove imported people when no longer relevant.

## Contacts

For conference and meeting follow-ups, use **I just met people** to add ORCID iDs and a context, then organize private tags, notes and tasks with due dates. There is also a bookmarklet that can start a contact import from an ORCID record page.

These are **your annotations**: the people named do not receive invitations, notifications, or a claim that they consented to being on your contact list.

## Groups

Curate a roster; record locally entered roles, expertise and contributions; choose which suggested works belong to a project; assign and resolve internal requests. Download a team pack scoped to chosen researchers, project outputs and dates. A project selection is an editorial decision, **not verified project attribution**.

See [Group view and collaboration evidence](groups.md) for public, shareable visualization of public records.

## Saved and personal backup

Save selected works and download a versioned **workspace backup**. Restoring a backup replaces the local workspace after validation and confirmation.

**Do not publish or casually distribute workspace backups:** they can contain your private contact notes, names, roles, requests and curated selections. There is a separate password-protected encrypted team-package workflow for deliberate transfer, which still requires secure password sharing.

## How much is actually private?

The hosted research-network workspace uses browser-local storage. Public ORCID record imports contact the ORCID public API. The optional private Team workspaces/personal cloud sync use Google services when configured and activated; **do not confuse them with the default browser-local workflow**. See [Trust and privacy](trust.md).

## Suggested five-minute test

Use the [sample research network](https://orcid-playground-889.web.app/network/?sample=1#groups). Follow someone, add a contact note, curate a group output, download a team pack, and tell us which task was confusing using the [feedback form](feedback.md).
